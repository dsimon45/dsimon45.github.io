- This website is built on the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.
- It is hosted with [GitHub Pages](https://docs.github.com/en/pages). 
- The font is Roboto
- In light mode the background color is [Cosmic Latte](https://en.wikipedia.org/wiki/Cosmic_latte), the average color of the universe. The accent color is [Byzantine](https://encycolorpedia.com/bd33a4).
- In dark mode the background color is [Chinese Black](https://encycolorpedia.com/141414) and the accent color is [Cosmic Spectrum Green](https://www.astro.ljmu.ac.uk/~ikb/press/color.html), the (incorrectly determined) average color of the universe.
